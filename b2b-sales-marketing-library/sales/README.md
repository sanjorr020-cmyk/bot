# sales/ — выявление потребности, презентация, закрытие сделки

Материалы для ведения сделки от первого разговора до подписания: квалификация лида, стадии воронки, презентация и предложение, разбор проигранных сделок.

Фрагменты с цитатами и строками источника — в [`fragments.md`](fragments.md).

## Материалы

Оценка: **методика** — опирается на известный фреймворк или внешние данные; **эвристика** — разумная рекомендация автора без ссылок; **шаблон** — готовые формулировки и таблицы без обоснования.

## Топ-3 для этого направления

1. **`sales-enablement`** (Marketing Skills). Самый полный набор: презентация по 10–12 слайдам, one-pager, battle card, разбор win/loss, сценарии демо. Главный принцип: материал должны использовать продажи, иначе он не работает. Полезен как чек-лист, а не как готовый текст.
2. **`lead-qualification`** (Business Skills). Готовая логика «MQL → SQL → AE» с банками вопросов по BANT, CHAMP и MEDDPICC. Важно: автор сам привязывает BANT к коротким сделкам (ACV до ~$25K), а для сложных советует другие фреймворки (MEDDPICC, CHAMP).
3. **`sales-pipeline-management`** (Business Skills). Стадии, которые определены по тому, что подтвердил покупатель: «Pain подтверждён словами клиента», «экономический покупатель назван по имени». Это помогает честно считать прогноз. Проценты по стадиям — ориентир, а не данные.

## Методики в этом направлении

- **BANT** — бюджет, полномочия, потребность, сроки. Нужна, чтобы быстро проверить, что лид стоит времени.
- **MEDDPICC** — метрики, экономический покупатель, критерии решения, процесс, идентификация боли, чемпион, конкуренты. Нужна для сложных сделок с комитетом.
- **JTBD** — какую работу клиент «нанимает» продукт делать. Помогает формулировать ценность через задачу, а не через функции.

## Осторожно

- Бенчмарки SDR (`sdr-benchmarks.md`) и проценты вероятности по стадиям — не из исследований. Перед тем как ставить их в план, сверьте с вашей историей сделок.
- Часть фреймворков (MEDDIC, BANT) придуманы для других контекстов; автор навыка сам предупреждает, что BANT плохо подходит для сделок с комитетом.
