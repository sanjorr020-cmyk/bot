# B2B-библиотека: продажи и маркетинг

Подборка рабочих материалов для B2B-продаж из трёх открытых репозиториев, разложенная по четырём направлениям:

| Папка | Что внутри |
|---|---|
| [`sales/`](sales/README.md) | Выявление потребности, презентация, закрытие сделки, воронка, квалификация |
| [`scripts/`](scripts/README.md) | Структура звонков, переписок, первого контакта и follow-up |
| [`objections/`](objections/README.md) | «Дорого», «подумаю», «нет бюджета», «уже есть подрядчик» и другие возражения |
| [`marketing/`](marketing/README.md) | Позиционирование, офферы, воронки, лидогенерация, психология покупателя |

Сами навыки (SKILL.md и справочные файлы) **установлены** в `.claude/skills/` репозитория и доступны Claude Code автоматически. Эта папка — навигация: какой навык за что отвечает, из какого репозитория он взят, насколько его стоит доверять, и короткие фрагменты (до 15 строк каждый) с указанием источника и строк. Полные тексты здесь не копируются.

## Что сделано по инструкциям установки

1. **Marketing Skills.** Использован вариант «Clone and Copy»: `skills/*` скопировано в `.claude/skills/`. Вариант `npx skills add` не запускался: он тянет и выполняет npm-пакет из реестра, а код из внешних источников я не выполнял без проверки. Вариант `/plugin install` в облачной сессии недоступен (только интерактивный CLI).
2. **Business Skills.** В README упомянуты `./install.sh` и симлинки из `.claude/skills/`, но в репозитории нет ни `install.sh`, ни папки `.claude/`, ни `AGENTS.md` / `MINDMAP.md`, на которые ссылается README. Поэтому каталоги навыков скопированы напрямую. Скрипт `install.sh` не запускался.
3. **SDR Playbook.** README предлагает скопировать `.agents/skills/` в `.claude/skills/`. Я положил файлы в подпапку `.claude/skills/sdr-operations-playbook/`, а не в корень `skills/`: `SKILL.md` этого навыка ищет ресурсы по пути `{SKILL_BASE}/../../resources`, и без подпапки и `.claude/resources/` ссылки не сходятся.
4. **Конфликты имён.** Шесть названий есть в обоих наборах: `ab-testing`, `churn-prevention`, `content-strategy`, `influencer-marketing`, `link-building`, `marketing-plan`. Версия из Business Skills установлена как `biz-<имя>` и с поправленным полем `name:` во frontmatter. Остальное не изменено.

Итог установки: **123 папки навыков** в `.claude/skills/` (53 + 69 + 1) и 2 файла ресурсов в `.claude/resources/`.

## Как пользоваться

- В Claude Code навыки подхватываются автоматически. Попросите, например, «напиши скрипт discovery-звонка» или «как ответить на „дорого“» — навык подключится по описанию.
- Если нужен конкретный материал, откройте фрагменты в нужной папке: там указаны файл, строки и путь к установленной копии.
- Перед использованием в письме или на звонке проверяйте цифры. Бенчмарки и сроки в навыках разного качества (см. оценки в README направлений).

## Ограничения

- Лицензия Business Skills и SDR Playbook не указана — используйте для внутреннего обучения, а публикацию наружу согласуйте с авторами.
- Персональные данные, контакты и названия клиентов в библиотеке не переносились. В фрагментах только публичные тексты навыков. Email-адреса в исходниках — шаблонные примеры (`company.com`, `example.com`).
- Код из репозиториев не запускался: скрипты, `npx` и установщики не выполнялись.
